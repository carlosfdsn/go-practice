# 🧠 Go Practice

Pequenos desafios e projetos feitos em **Go (Golang)** para praticar lógica de programação, estruturas de dados e resolução de problemas.

A ideia é resolver os problemas **sem IA e sem copiar soluções**, tentando chegar à solução sozinho.

## 📚 Projetos

| #  | Projeto            | Conceito            |
| -- | ------------------ | ------------------- |
| 01 | Frequency Counter  | Maps, slices, loops |
| 02 | Find Maximum  | Slices, loops, comparisons  |

## 🎯 Objetivo

* Melhorar minha lógica de programação
* Aprender Go na prática
* Praticar estruturas de dados e algoritmos
* Resolver problemas progressivamente mais difíceis
* Registrar minha evolução
