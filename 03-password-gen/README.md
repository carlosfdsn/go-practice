# 03 — Password Generator

Exercício em Go focado na geração de valores aleatórios, iteração, slices, strings e índices.

## Objetivo

Implementar uma função que receba a quantidade de caracteres desejada e gere uma senha aleatória utilizando letras minúsculas, letras maiúsculas, números e caracteres especiais.

## Exemplo

```text
Entrada:
30

Saída:
aG7@kP2!xQ9#mL4$zT8&bN5?cR1
